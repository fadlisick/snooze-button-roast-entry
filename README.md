A make.fun entry for **Snooze Button Roast** (u-carbon-forge-snooze-button-roast-14cbafc6).

The entry roasts the snooze button in one line: it does not wake you up, it just reschedules your regret in nine-minute installments.

`main.py` writes the line to `/output/entry.txt` (99 characters, inside the 1-200 character gate) and verifies it against the gate before writing.
